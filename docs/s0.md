# S0: passthrough

`src/ctxd/main.mojo` routes, `src/ctxd/curl.mojo` is the libcurl client (dlopen, `/usr/lib/libcurl.so.4`).

- Build: `mojo build -I src src/ctxd/main.mojo -o .work/ctxd`. Run in a dir with `ctxd.toml`, or set env.
- Config (env wins): `port` / `CTXD_PORT` (default 8787), `messages` / `CTXD_UPSTREAM_MESSAGES`
  (default `https://api.anthropic.com`), `chat` / `CTXD_UPSTREAM_CHAT` (default `https://openrouter.ai/api`).
  The request target is appended to the base URL.
- Routes: POST `/v1/messages*` and POST `/v1/chat/completions`. 404 other paths, 405 other methods, 502 when the upstream is unreachable.
- Request headers forward as-is except host, content-length, connection, keep-alive, te, trailer, transfer-encoding,
  upgrade, expect, accept-encoding, proxy-*. Response: status, content-type and body only; the body is re-chunked.
- Gate: `tests/gate-s0.sh` (local fake upstream, `tools/s0_oracle.py`). Probe: `tests/curl_probe.mojo`.
- `external_call["curl_easy_setopt"]` cannot take both an Int and a function pointer in one build
  (conflicting-signature error); every libcurl call goes through `OwnedDLHandle.call`.
