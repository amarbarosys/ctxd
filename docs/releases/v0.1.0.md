## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
Context-folding proxy for online and local LLM APIs. It sits between a client such as Claude Code
and the API, folds old context into summaries, and keeps a local store. It listens on localhost only.

## Highlights

- Point `ANTHROPIC_BASE_URL` at ctxd and the client works unchanged; without a summarizer it is a plain passthrough.
- Old turns fold into summaries; the full text stays in a local store that `ctx_expand` and `ctx_search` read back.
- Runs as a Docker image bound to 127.0.0.1 only.
